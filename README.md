# 🎫 Ticket

A simple and responsive **Ticket Management UI** built using modern frontend technologies. This project focuses on creating a clean ticket interface with reusable components and an easy-to-use design.

## 🚀 Features

* 🎫 Ticket creation interface
* 📋 Display ticket information
* 🔍 Easy ticket management
* 🧩 Reusable components
* 📱 Responsive design
* 🎨 Clean and user-friendly UI
* ⚡ Fast and lightweight application

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Git & GitHub

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/anmolagrahari24/Ticket.git
```

### 2. Navigate to the project

```bash
cd Ticket
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the application in your browser at:

```text
http://localhost:5173
```
